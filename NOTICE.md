# Portfolio notice

This repository is a curated architecture and engineering portfolio.

Each project page states whether its implementation is public, private, or planned for selective publication. Where a public source repository is linked, that repository’s own license governs its source code. A case study for a private implementation does not grant source access, publish the private repository, or extend any source-code license by implication.

The portfolio prose, diagrams, screenshots, and synthetic scenarios are provided for technical review and discussion unless a separate license states otherwise. They describe selected product behavior, architecture, implementation evidence, engineering decisions, limitations, and deployment boundaries; they are not substitute source trees or operational runbooks.

The examples intentionally omit production data, credentials, private messages, host-specific paths and identifiers, proprietary prompt or persona configuration, security-sensitive thresholds, deployment secrets, and other authority-bearing state that is not necessary to understand the systems.
